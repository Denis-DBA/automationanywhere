# Bot Automation Anywhere — informações de exportação

O bot original `RPA_Processamento_Solicitacoes` foi criado na **Automation Anywhere Community Edition**.

**O ZIP de exportação do bot não está incluído neste repositório.** No ambiente utilizado, não foi disponibilizada a exportação de pacote pelo Control Room. Para não produzir um artefato fictício, publicamos a documentação detalhada das 12 ações e a captura de tela do editor quando disponível.

Quem quiser reproduzir o fluxo deve criar um novo Task Bot no Automation Anywhere e configurar as ações descritas no [README do projeto](../README.md), substituindo os caminhos locais da planilha.
